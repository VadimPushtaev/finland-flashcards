# Canonical Homebrew flashcards

**Edit these YAML files, not the generated TXT or Kahoot XLSX.**

The twelve `hb-c01.yaml` through `hb-c12.yaml` files are the canonical source for
**1,034** Swedish multiple-choice flashcards, organized in book section order.
Each card has an explicit, permanent ID, independent of its wording or position.
Changing text does **not** change its FSRS identity. Do not reuse an existing ID
for a completely different question.

## Export workflow

- `make combine-homebrew` renders section-level Anki TXT from these YAML files,
  then builds each chapter's `ALL.txt`. `make` additionally rebuilds Kahoot XLSX.
- `make check-homebrew` checks TXT freshness without changing any output.
- The site reads YAML **directly** and no longer hashes TXT content to identify
  cards. The TXT files are compatibility outputs for Anki and Kahoot, not editable
  sources of truth.
- The generated TXT format and its 120-character question / 70-character answer
  limits remain unchanged. Kahoot continues to consume derived TXT.
- Original provenance and editorial analysis remain available in the preexisting
  `card_creator/homebrew/card_sources/` sidecars. Their `row_sha256` fingerprints
  refer to exported TXT rows; they are *not* stable card identifiers.
- The feature has never been deployed/used with real practice progress, so
  migrating the old content-hash identifiers is deliberately out of scope.

## YAML schema

```yaml
schema_version: 1
chapter_id: hb-c01
language: sv
cards:
  - id: hb-c01-lage-0001
    section_id: hb-c01-lage
    category: Finland i Norden
    question: Vilka fem länder hör till Norden?
    options:
      - { id: a0, text: "Sverige, Norge, Danmark, Island och Estland" }
      - { id: a1, text: "Finland, Sverige, Norge, Danmark och Island" }
      - { id: a2, text: "Finland, Sverige, Danmark, Island och Lettland" }
      - { id: a3, text: "Finland, Norge, Danmark, Island och Ryssland" }
    correct_option_id: a1
```

Cards must have unique permanent IDs; the correct option is referenced by its
own ID. Category must match the corresponding chapter section's original title.

## Future translations and word boundaries

**No Russian translations are generated by this change.** The initial card YAML
holds all Swedish source text and stable IDs, ready for a separate reviewed
translation layer. Questions and options have stable surface IDs:

- `<card-id>:q` for the question.
- `<card-id>:a0`, `<card-id>:a1`, `<card-id>:a2`, `<card-id>:a3` for
  each option.

Use the same word-span annotation model as the existing book translations:
a reviewed record contains `source_id`, original Swedish `sv`, full-sentence
Russian `ru`, and a `vocabulary` list of lemmas, meanings and character-based
`spans` into that exact source text. Example future translation record:

```yaml
source_id: hb-c01-lage-0001:q
sv: Vilka fem länder hör till Norden?
ru: Какие пять стран относятся к Северной Европе?
vocabulary:
  - lemma: land
    pos: NOUN
    context_ru: страна
    general_ru: страна, земля
    spans:
      - { start: 10, end: 16, text: länder }
```

Reviewed translation files belong in `data/homebrew/ru/cards/` and must carry
source-content fingerprints plus review metadata, like the existing lesson
translation pipeline. This preserves stable card IDs even when Russian text is
updated. The existing API fails closed if no complete matching translation exists;
the Swedish card remains usable. Annotation spans and Russian translations will
be generated by a future dedicated translation skill, **not** as part of this
migration. Neither invented translations nor meaningless empty word spans are
committed here.
