# Russian Homebrew data

This directory reserves the permanent home for Russian section translations,
chapter headings, terminology, and review metadata. No production translations
have been created yet. The empty glossary is ready for reviewed terminology.

Follow the [translation workflow](../../../translation/homebrew/README.md) and
[data schema](../TRANSLATION_SCHEMA.md). Translation jobs create `sections/`,
`headings/`, and `reviews/` as needed. Preserve the Swedish anthology's source
attribution and reuse terms; translation does not change source ownership or make
this an official exam textbook.
